MY ENGLISH 설치 안내

1. ZIP 압축을 풀어 모든 파일을 HTTPS 정적 웹호스팅에 업로드합니다.
2. 업로드한 HTTPS 주소를 Android Chrome에서 엽니다.
3. Chrome 메뉴(⋮)에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.
4. 홈 화면의 MY ENGLISH 아이콘으로 실행합니다.

기능: DAY 1~30, 핵심 어휘, 실용 문장, 듣기(TTS), 말하기 답변 저장, 지원 브라우저 음성 입력(STT), SPA 질문, 퀴즈, 로컬 진도 저장, 오프라인 캐시.

주의: 이 앱은 APK가 아니라 PWA입니다. ZIP만으로 자동 설치되지 않으며 HTTPS 호스팅이 필요합니다. 진도는 현재 기기의 브라우저에 저장되어 기기 간 자동 동기화되지 않습니다. 음성 기능은 브라우저/마이크 권한/네트워크 지원 여부에 따라 제한될 수 있습니다.
