MY ENGLISH - 무료 모드 안내

구성
- index.html: 앱 화면 및 기능
- lessons.js: DAY 1~30 학습 자료
- avatar-emma.jpg: 여성 아바타 이미지
- manifest.json / sw.js / icon.svg: PWA 설치 및 캐시 파일

무료로 제공되는 기능
- 메뉴 이동, DAY 1~30 학습, 학습 완료 기록
- 브라우저 음성 합성(TTS)
- 브라우저가 지원하는 경우 음성 인식(SpeechRecognition)
- 대화 기록과 사용자 학습 메모의 기기 내부 저장
- 규칙 기반의 간단한 회화 응답

중요한 제한
- 이 버전은 생성형 AI 서버에 연결되어 있지 않습니다.
- 실제 AI 원어민 자유 대화, 자동 문법 교정, 클라우드 대화 기억은 제공하지 않습니다.
- 아바타는 정지 이미지이며 정밀 입 모양 동기화/실시간 표정 애니메이션은 아직 없습니다.
- 음성 인식은 브라우저/기기/네트워크 지원에 따라 작동하지 않을 수 있습니다.
- 마이크 사용은 HTTPS 환경과 브라우저 권한 허용이 필요합니다.
- 대화/메모는 현재 기기의 브라우저 저장소에만 저장됩니다. 브라우저 데이터 삭제 시 사라질 수 있습니다.
